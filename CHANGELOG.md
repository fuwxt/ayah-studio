# Changelog

## 1.0.0 — 2026-11-16

First public release.

- Create Quran recitation (tilawat) reels for TikTok, Instagram Reels, Facebook Reels and YouTube Shorts.
- Import mp3/wav/m4a/ogg/flac recitations with waveform, trim, fades, volume, mute and preview speed.
- Add ayah text by pasting or importing it, fetching it online from Quran.com with EveryAyah audio, or extracting it offline with whisper.cpp.
- Offline forced alignment and a timeline editor with drag handles, nudges, multi-select and play-from-here.
- WebGL2 renderer with correct Arabic shaping, word-synced highlight, Deep Glow HDR bloom, rain-on-glass, and respectful animation presets.
- 6 built-in themes, custom themes (.json import/export), 7 bundled Quran fonts plus custom font import.
- Aspect ratios 9:16, 1:1, 4:5, 3:4, 16:9, 21:9 and custom sizes, up to 4K, with safe-area guides.
- Frame-accurate FFmpeg export to MP4 H.264/H.265, WebM, ProRes and PNG sequence, with GPU encoding, batch ratios, and with/without audio.
- Publish panel with a generated caption and hashtags, plus official upload links for TikTok, Instagram, Facebook and YouTube.
- English, Urdu and Arabic interface with RTL support.
- Windows installer, portable exe and zip; macOS dmg and Linux AppImage via GitHub Actions.
